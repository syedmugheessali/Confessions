# Confessions

> *Speak into the void. It won't remember.*

**Confessions** is an ephemeral space for sharing thoughts, secrets, and things left better unsaid.

Write something. Give it a lifespan. Let it disappear.

## ✦ What it is

- Anonymous-first confessions
- Self-removal for your own posts
- Minimal, distraction-free interface

## ✦ Built with

**MERN Stack** · React · Node.js · Express · MongoDB
